# Green Reader iOS

An iOS ARKit app for reading golf greens using the iPhone camera.

## MVP Features

- AR camera view
- Tap to mark ball
- Tap to mark hole
- Estimate distance
- Estimate slope
- Estimate break
- Adjustable Stimp speed
- Aim recommendation

## Status

Prototype in progress.

## Next Features

- AR aim line overlay
- Better slope mapping
- Reset markers without restarting AR
- Save readings
- Course/green library
